# ── 오류 코드 — 고객 상담(docs/58) ─────────────────────────────────────
상담을 찾을 수 없습니다.
= お問い合わせが見つかりません。

상담원만 쓸 수 있습니다.
= サポート担当者のみ利用できます。

종료된 상담입니다. 새로 문의해 주세요.
= 終了したお問い合わせです。新しくお問い合わせください。

다른 상담원이 이미 맡은 상담입니다.
= 他のサポート担当者がすでに対応しているお問い合わせです。

먼저 상담을 맡아 주세요.
= 先にお問い合わせの担当を引き受けてください。

메시지를 입력해 주세요.
= メッセージを入力してください。

종료된 상담만 평가할 수 있습니다.
= 終了したお問い合わせのみ評価できます。

이미 평가한 상담입니다.
= すでに評価済みのお問い合わせです。

평가는 1~5점, 의견은 500자까지 남길 수 있습니다.
= 評価は1〜5点、ご意見は500文字まで入力できます。

메모는 2000자까지 남길 수 있습니다.
= メモは2000文字まで入力できます。

내가 맡은 상담만 반납할 수 있습니다.
= 自分が担当しているお問い合わせのみ返却できます。
